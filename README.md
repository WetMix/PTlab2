# Лабораторная работа №2: Изучение фреймворка MVC

## Постановка задачи
Разработка веб-приложения на ASP.NET Core MVC, реализующего магазин товаров для сада с логикой изменения цены при уменьшении количества.

## Описание проекта
Магазин позволяет просматривать список товаров, их количество и цену. При покупке количество уменьшается, и если оно падает ниже половины исходного, цена увеличивается на 20%.

## Используемые технологии
- **Язык**: C# (.NET 8)
- **Фреймворк**: ASP.NET Core MVC
- **ORM**: Entity Framework Core (SQLite)
- **Тестирование**: xUnit
- **CI/CD**: GitHub Actions, Railway
- **Хостинг**: Railway

## CI/CD
Проект использует GitHub Actions для автоматического запуска тестов и Railway для автоматического развертывания при пуше в ветку `main`.


## Выводы
В ходе работы были изучены принципы MVC, настроена система CI/CD с автоматическим тестированием и развертыванием на облачной платформе.
